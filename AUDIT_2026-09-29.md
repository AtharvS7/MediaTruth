# MediaTruth codebase audit — 29 September 2026

Production readiness: **35/100, blocked for enterprise release**. This is an engineering triage score, not measured detection accuracy. The application is a working prototype with major scientific-validity, database-policy, dependency, and operational gaps. Earlier audit documents describe previous work, not certification of the current product.

## Scope and evidence

Reviewed the FastAPI entry point, all route/service/inference/util modules, backend tests, Next.js auth/upload/results/history flows and chart components, Supabase SQL, environment examples, CI, Docker/Render deployment files, development launcher, and training notebook. Reviewed existing uncommitted changes and preserved them. Static review does not establish deployed behavior. No production database, customer media, hosted model endpoint, cloud billing account, or trained benchmark was tested.

## How the project works

1. Next.js uses Supabase Auth to obtain a bearer token. Axios uploads multipart media to FastAPI.
2. Backend verifies the token through Supabase, validates MIME/size and basic magic bytes, and saves a temporary upload.
3. Images run two learned classifiers, ELA/block-boundary heuristics, and EXIF inspection in executor threads. An arithmetic aggregator creates four normalized category scores.
4. Videos are sampled with OpenCV, saved as JPEG frames, and processed through the same image pipeline, eight frames at a time. The video verdict averages frame scores. There is no audio, face tracking, temporal model, or original-container provenance analysis.
5. Backend writes a summary to `scans` and JSON details to `analysis_results` using a service-role client. The frontend initially caches results in sessionStorage, then reads stored reports through the API.
6. Local inference loads checkpoints or Hugging Face pipelines; `USE_HF_API=true` instead sends image bytes to hardcoded external endpoints. Supabase provides PostgreSQL **and authentication**; replacing it with plain Postgres alone would break login.

## Metadata export delivered in this milestone

`POST /image/clean-metadata` (authenticated, 5/minute) and `/metadata` UI export JPEG/PNG/WebP/BMP to a fresh PNG using decoded pixels. Applies EXIF orientation, preserves alpha, rejects animation, enforces 50MB upload and 16MP decode limits, removes source metadata by not copying container data, returns no-store download, and cleans temporary files. No analysis/model call or database insert is needed for export. Removing color profiles may affect appearance; original input is untouched.

This does **not** remove every trace of AI. Pixel watermarks, visual/statistical traces, external copies and rediscoverable provenance may remain. [C2PA documents durable credentials](https://c2pa.org/faqs/); [Google documents invisible SynthID watermarks](https://deepmind.google/models/synthid/). No watermark-removal or universal-undetectability claim is made.
